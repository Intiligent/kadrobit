# Главная страница

Публичная страница `/` для гостей: что делает Kadrobit. Вошедших пользователей `HomeController` сразу отправляет в библиотеку. Дизайн — `Landing v3.dc.html` в проекте Claude.

## Блоки

| Блок | Компонент | Что показывает |
|---|---|---|
| Шапка и подвал | `layouts/LandingLayout.vue` | Логотип, якоря по разделам, переключатель языка (`el-segmented`), «Войти» и «Создать аккаунт» |
| Первый экран | `pages/home/index.vue`, `components/home/PhotoWall.vue`, `HeroDemoCard.vue` | Заголовок, текст, кнопка регистрации; справа три колонки фото едут вверх и вниз, поверх — карточка работы с анимацией: загрузка → заголовок и ключевые слова → проверки и отправка на три стока |
| Маркетплейсы | `components/home/StockMarquee.vue` | Бегущая строка стоков с протоколом и строка о стоках без автоматической загрузки. Список приходит из базы |
| Как это работает | `components/home/HowItWorks.vue` | 4 шага кадрами плёнки, текущий подсвечен |
| Возможности | `components/home/FeatureGrid.vue` | 6 плиток разного размера: AI-метаданные, правила стоков, пачки, статусы, библиотека, загрузка с сервера |
| Проверки | `components/home/CheckPrints.vue` | Три отпечатка, на которые при прокрутке ставятся штампы «Отправится», «Требует внимания», «Не отправится» |

## Данные

`HomeController::index` передаёт:

- `marketplaces` — `[{code, name, protocol}]` активных маркетплейсов с загрузкой по FTP/FTPS/SFTP (`UploadProtocol::fileTransfer()`);
- `unsupported` — названия маркетплейсов с `upload_protocol = web` (iStock, Getty Images, Canva Creators).

Остальное содержимое демо (имена файлов, ключевые слова, статусы) — постоянные примеры в `utils/homeDemo.js`, тексты — `lang/{ru,en}/home.php`.

## Анимации

- Все демо идут от одного счётчика `useTicker()` (`composables/useTicker.js`): 130 шагов по 100 мс, пауза в скрытой вкладке. Состояние кадра — чистые функции `heroDemo`, `filmFrame`, `routePosition`, `batchCount` (`utils/homeDemo.js`, тесты в `tests/js/homeDemo.test.js`).
- Стена фото и бегущая строка — CSS-анимации.
- `v-reveal` (`directives/reveal.js`, зарегистрирована в `app.js`) плавно поднимает заголовки и плитки при первом появлении на экране; с функцией в значении — вызывает её (штампы в «Проверках»).
- При `prefers-reduced-motion: reduce` всё стоит на конечном кадре, бегущая строка переносится по строкам.

## Язык

Переключатель шлёт `POST /locale` (`LocaleController`): у гостя язык сохраняется в сессии (его читает `SetLocale`), у вошедшего — в настройке `general.locale`. Затем страница перезагружается, как в «Настройки → Общие».

## Шрифты и цвета

- Заголовки — Instrument Serif (`bunny()` в `vite.config.js`, переменная `--font-serif` в `tailwind.css`). В нём нет кириллицы, поэтому русские заголовки набираются Georgia.
- Цвета только из переменных Element Plus (`--el-color-primary`, `--el-text-color-*`, `--el-border-color-*`, `--el-fill-color`). Тёмные блоки — фон `--el-text-color-primary`. Страница всегда светлая, в том числе в тёмной теме системы.

## Фотографии

`public/images/home/*.webp` — временные снимки с picsum.photos (фото Unsplash, бесплатная лицензия), имя `{id}-{ширина}x{высота}.webp`. Перед запуском заменить на работы авторов с разрешением на использование; пути собирает `homeImage()` в `utils/homeDemo.js`.
