# KB-54 - Marketplaces: расширение Chrome для работы с кабинетами стоков

Задача: [KB-54](https://github.com/Intiligent/kadrobit/issues/54).

## Цель

Одно расширение Chrome для всех стоков: оно связывает браузер автора с его аккаунтом Kadrobit и делает на сайте стока то, что нельзя сделать с сервера. У стоков нет публичного API, вход закрыт капчей или защитой от ботов, и Submit возможен только в их интерфейсе. Автор уже проверил и одобрил работы в Kadrobit, поэтому повторное подтверждение на сайте стока — лишний шаг.

Расширение работает только в уже открытой сессии автора: пароли стоков оно не видит и не хранит, капчу не обходит.

Эта задача описывает общие требования и каркас. Особенности каждого стока — в подзадачах, по порядку:

- [ ] [KB-79](https://github.com/Intiligent/kadrobit/issues/79) Основа расширения и API Kadrobit для него
- [ ] [KB-84](https://github.com/Intiligent/kadrobit/issues/84) Shutterstock — категории, метаданные и отправка на модерацию
- [ ] [KB-80](https://github.com/Intiligent/kadrobit/issues/80) 123RF — Proceed и отправка на проверку
- [ ] [KB-81](https://github.com/Intiligent/kadrobit/issues/81) Adobe Stock — CSV, загрузка и отправка на проверку

## Подключение к Kadrobit

- Авторизация через Laravel Passport: OAuth 2 Authorization Code с PKCE, публичный клиент без секрета.
- Расширение открывает окно авторизации Kadrobit через `chrome.identity.launchWebAuthFlow`. Автор, уже вошедший на сайт, нажимает «Разрешить», и расширение получает access-токен со скоупами и refresh-токен.
- Запасной способ — персональный токен: его выпускают в настройках Kadrobit и вставляют в расширение вручную.
- Токен расширения даёт доступ только к API расширения, ни к чему больше.
- В Kadrobit виден список подключённых расширений, любое можно отозвать; после отзыва расширение отключается сразу.
- Кнопка «Выйти» в расширении отзывает токен и позволяет войти под другим аккаунтом.

## Базовые функции

У каждого стока своя механика: как найти файлы Kadrobit, что сделать до отправки (у 123RF — Proceed, у Adobe без SFTP — загрузить файлы через портал), как отправить и как узнать статус модерации. Общее — каркас адаптера и то, что адаптер сообщает в Kadrobit. Механика каждого стока описывается в его подзадаче.

### 1. Обнаружение загруженных файлов

- [ ] На сайте стока расширение находит файлы, загруженные Kadrobit, и сообщает платформе, что они дошли и обработались. Это нужно для статуса или прогресса публикации в Kadrobit.
- [ ] Файл на стоке сопоставляется с публикацией по имени файла, которое Kadrobit задаёт при загрузке, а где имени мало — ещё по размеру или дате.
- [ ] Внутренний ID работы на стоке передаётся в Kadrobit и сохраняется в `external_id` публикации, ссылка на работу — в `external_url`. По этому ID потом сопоставляются статусы модерации, продажи и любые действия с работой.

### 2. Отправка на модерацию

- [ ] Настройка «Автоматическая отправка» у каждого подключённого стока отдельно, по умолчанию включена.
- [ ] Если настройка включена, расширение само отправляет обнаруженные работы на модерацию. Перед отправкой оно проверяет описание, ключевые слова, категории и прочие поля стока и при необходимости заполняет их данными из Kadrobit. Включая настройку, автор соглашается и с действиями, которые на сайте стока означают принятие условий (Proceed на 123RF); это сказано в подсказке к настройке.
- [ ] Если настройка выключена, расширение только обнаруживает файлы, а Submit автор делает на сайте сам.
- [ ] Главный источник метаданных — Kadrobit: правки автора на сайте стока перезаписываются при следующем заполнении.
- [ ] После записи метаданных публикация в Kadrobit отмечается как обновлённая: пометка «изменено после отправки» снимается.
- [ ] Для каждого стока проверить правила: где автоматизация кабинета запрещена, есть риск блокировки аккаунта. Результат записать в `docs/marketplaces/`.

### 3. Статусы модерации

- [ ] Адаптер опрашивает статусы работ на стоке (на модерации, принята, отклонена) и передаёт их в Kadrobit со временем сверки.
- [ ] Статусы обновляются, только когда у автора открыт сайт стока, поэтому Kadrobit и попап показывают, когда была последняя сверка.

### 4. Надёжность

- [ ] Ответы внутреннего API стока проверяются по форме: если сток его поменял, расширение показывает понятную ошибку и ничего не отправляет, а не ломается молча.

## Интерфейс

Панель на сайт стока не встраиваем: всё показывается в попапе расширения, в три блока. Списка работ в попапе нет, только статистика.

1. **Аккаунт** — есть всегда: аккаунт Kadrobit и кнопка «Выйти».
2. **Общая статистика** по платформе: загружено, на модерации, отклонено.
3. **Текущий сток** — только когда открыт сайт стока: статистика по нему, время последней сверки и последнее действие расширения (например, «найдено 12 файлов, отправлено 10, ошибок 2»). На других сайтах блока нет.

Тексты расширения — на английском и русском, с теми же ключами, что в `lang/`.

## Расширение

- Manifest V3. Права только на домены стоков из подзадач и домен Kadrobit.
- Сборка, версия и инструкция по установке — в `docs/`.
- Публикация в Chrome Web Store. Расширение, которое действует в чужих кабинетах, может не пройти проверку магазина; запасной путь — распакованное расширение или установка по ссылке.

## Изменения в Kadrobit

- [ ] Колонка `external_url` в `asset_listings` рядом с `external_id`: в create-миграцию и пересборка таблицы через `TableRebuilder` (`docs/development.md`, «Колонка в середине таблицы»).
- [ ] Статус модерации публикации и время последней сверки — отдельно от статуса доставки (`status`: queued, sending, sent, failed, cancelled).
- [ ] Настройка автоматической отправки у подключённого стока.
- [ ] API расширения и управление подключёнными расширениями в настройках.

## Планы (не входит в эту задачу)

- Импорт портфолио: новый автор с работами на стоках и пустым Kadrobit. Расширение проходит по работам автора на стоке и передаёт в Kadrobit их ID, метаданные, статусы и превью. Механизм — отдельно под каждый сток.

## Критерии приёмки

- Расширение подключается к Kadrobit через OAuth с PKCE и через персональный токен; выход отзывает токен; подключение видно в Kadrobit и отзывается оттуда.
- На каждом из стоков в подзадачах работа, отправленная из Kadrobit, доходит до модерации без ручного заполнения полей, если для стока включена автоматическая отправка.
- При выключенной настройке ничего не отправляется.
- В Kadrobit видны ID работы на стоке, ссылка на неё, статус модерации и время сверки.
- Попап показывает три блока, блок стока — только на сайте стока.
- `docs/marketplaces/README.md` обновлён.

## Шаги для владельца

- [ ] Аккаунт разработчика в Chrome Web Store (разовый взнос).
- [ ] Закрепить ID расширения (`key` в манифесте), чтобы redirect URI не менялся.
- [ ] Зарегистрировать OAuth-клиента Passport с redirect URI `https://<extension-id>.chromiumapp.org/`.
